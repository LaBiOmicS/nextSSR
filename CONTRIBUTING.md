# Contributing to nextSSR

Thank you for considering contributing to **nextSSR**! We welcome contributions from community members, researchers, and developers.

## How to Contribute

### 1. Reporting Bugs
- Use the GitHub Issue Tracker.
- Use the **Bug report** template.
- Include OS, Python version, error tracebacks, and reproducible steps.

### 2. Suggesting Features
- Open an issue using the **Feature request** template.
- Explain the motivation and use case clearly.

### 3. Submitting Pull Requests
1. Fork the repository on GitHub.
2. Create a new feature branch (`git checkout -b feature/my-new-feature`).
3. Make your changes and write unit tests in `tests/`.
4. Ensure pytest passes cleanly (`pytest`).
5. Commit your changes (`git commit -m "Add new feature"`).
6. Push to your branch (`git push origin feature/my-new-feature`).
7. Create a Pull Request targeting `main`.
