Next-Generation Microsatellite Mining & PCR Primer Design

nextSSR is a high-performance bioinformatics platform for identifying Simple Sequence Repeats (SSRs), designing thermodynamic PCR primers, and running in silico e-PCR simulations.

Usage & Examples

Code & Command Snippets

Command 1: Mine SSRs & Design Primers

CLI 
nextssr run --input genome.fasta --output-dir ./results --threads 8 --flank-len 100 --primer-opt-tm 58.0 --format gff3,tsv,json

Command 2: In Silico e-PCR Simulation

CLI 
nextssr epcr --fasta target_genome.fasta --forward GATTACAAGCTACG --reverse ACGTACGTACGT --max-mismatch 2 --output epcr_results.tsv

Python API Programmatic Integration

Python 3.8+ 
from nextssr import SSRFinder, PrimerDesigner, SSRConfig

config = SSRConfig(flank_len=100, opt_tm=58.0)
finder = SSRFinder(config)
result = finder.analyze_sequence(seq_id="Chr01", sequence="ATCGATCGATCGCAGCAGCAGCAGCAGCAGCAGCAGATCG")

designer = PrimerDesigner(opt_tm=58.0)
for ssr in result.ssrs:
    pair = designer.design_primers(ssr.flank_5p, ssr.sequence, ssr.flank_3p)
    print(f"Locus: {ssr.seq_id} | Motif: {ssr.motif} | Repeats: {ssr.repeats}x | Status: {pair.status}")

}

Snakemake Rule Integration

Workflow 
rule nextssr_mining:
    input: fasta="genomes/{sample}.fasta"
    output: gff="results/{sample}.gff3", tsv="results/{sample}.tsv"
    conda: "bioconda::nextssr=0.1.0"
    shell: "nextssr run --input {input.fasta} --output-dir results --threads 8 --format gff3,tsv"
