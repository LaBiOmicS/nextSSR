Microsatellite Discovery & e-PCR

High-performance, standalone Simple Sequence Repeat (SSR) identification, thermodynamic PCR primer synthesis, and in silico electronic PCR validation engine for large-scale polyploid genomics.

Key Engine Capabilities

Engineered for extreme throughput, accuracy, and scientific reproducibility.

Multi-Core & GPU Vectorized

Streaming low-memory FASTA parser processing gigabase-scale assemblies in parallel with native CPU multi-threading and optional CUDA GPU hardware acceleration.

Thermodynamic Primer Design

Native primer synthesis leveraging SantaLucia (1998) nearest-neighbor thermodynamics for accurate Tm, GC%, and penalty function optimization.

In Silico e-PCR Simulator

Electronic PCR simulation supporting IUPAC degenerate base matching, 3'-end extension anchor mismatch filtering, and off-target risk profiling.

FAIR RO-Crate & GFF3

Outputs Sequence Ontology (SO:0000289) annotations in standard GFF3 and complete W3C RO-Crate (JSON-LD) computational lineage graphs.

PyPI & Bioconda Ecosystem

Seamlessly packaged for PyPI (`pip install nextssr`), Bioconda (`conda install -c bioconda nextssr`), Docker, and Apptainer/Singularity containers.

100% Algorithmic Precision

Validated across plant, fungal, and bacterial genomes, achieving 100% precision match against MISA while executing up to 15x faster.

Quick Start & Usage

Run analysis and primer design in a single command.

1. Run SSR Identification and Primer Design CLI
nextssr genome.fasta -o results/ --threads 16 --opt-tm 60.0
2. Run In Silico e-PCR Simulation e-PCR

# Test primer pair against template FASTA

nextssr epcr -f genome.fasta -F GATTACAAGCTACG -R ACGTACGTACGT -o epcr_amplicons.tsv

# Batch validate all primers from a nextSSR run report

nextssr epcr -f genome.fasta -p results/primers/nextssr_primers.tsv -m 2 -o epcr_batch.tsv
