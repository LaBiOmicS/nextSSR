Next-Generation Microsatellite Mining & PCR Primer Design

nextSSR is a high-performance, standalone bioinformatics platform for identifying Simple Sequence Repeats (SSRs), designing thermodynamic PCR primers, and running in silico e-PCR simulations.

Core Capabilities

Why Choose nextSSR?

Built from the ground up for modern genomic scale, high speed, and complete scientific compliance.

High-Speed Parallel Engine

Multi-threaded genome scanning engine capable of processing whole chromosomes in seconds, outperforming legacy single-threaded tools on large assemblies.

SantaLucia 1998 Thermodynamics

Automated primer pair selection using exact Nearest-Neighbor thermodynamic calculations (Tm, GC%, hairpin stability, and cross-dimer penalties).

In Silico e-PCR Simulator

Integrated electronic PCR module to test primer binding, check 3'-end extension mismatches, and support IUPAC degenerate bases across target genomes.

FAIR Specification Outputs

Generates standardized GFF3, JSON, TSV, and HTML interactive reports for direct integration with genome browsers (IGV, JBrowse) and pipelines.

Zero External Dependencies

Fully self-contained python package. No need to install external C++ dependencies or legacy binary wrappers like Primer3 or Perl interpreters.

Bioconda & PyPI Native

Installable in a single command via Conda, Mamba, or Pip, with full support for Linux, macOS, Windows, and CI/CD HPC clusters.

Usage Guide

CLI & Python API Usage

Run nextSSR straight from your terminal or integrate it into your Python workflows.

Command 1: Mine SSRs & Design Primers

CLI

Scans a FASTA sequence file, identifies all microsatellites (mono-to-hexanucleotides), designs thermodynamic primers, and outputs GFF3 + TSV reports. 

# Run nextSSR on a genome FASTA with 8 threads
nextssr run \
  --input genome.fasta \
  --output-dir ./results \
  --threads 8 \
  --flank-len 100 \
  --primer-opt-tm 58.0 \
  --format gff3,tsv,json

Command 2: In Silico e-PCR Simulation

CLI

Tests primer pairs against template genomes, evaluates binding site specificity, checks 3'-extension mismatches, and supports IUPAC degenerate bases. 

# Simulate e-PCR amplification
nextssr epcr \
  --fasta target_genome.fasta \
  --forward GATTACAAGCTACG \
  --reverse ACGTACGTACGT \
  --max-mismatch 2 \
  --output epcr_results.tsv

Python API Programmatic Integration

Python 3.8+

Import nextSSR modules directly inside custom Python scripts, Jupyter notebooks, or computational pipelines. 

from nextssr import SSRFinder, PrimerDesigner, SSRConfig

# 1. Initialize configuration
config = SSRConfig(flank_len=100, opt_tm=58.0)

# 2. Mine SSR loci from sequence
finder = SSRFinder(config)
result = finder.analyze_sequence(seq_id="Chr01", sequence="ATCGATCGATCGCAGCAGCAGCAGCAGCAGCAGCAGATCG")

# 3. Design thermodynamic PCR primers
designer = PrimerDesigner(opt_tm=58.0)
for ssr in result.ssrs:
    pair = designer.design_primers(ssr.flank_5p, ssr.sequence, ssr.flank_3p)
    print(f"Locus: {ssr.seq_id} | Motif: {ssr.motif} | Repeats: {ssr.repeats}x | Status: {pair.status}")
