      How nextSSR solves it

      One engine, from repeat to report.

      Detect

      MISA     regex scan, left to right
  …CCCCGAAAAAAAAAAAAAAAGAAGAAGAAGAAGCC…
  (A)15 ✓   (AAG)5 ✗ consumed by the rejected match

nextSSR  maximal runs, every unit size
  …CCCCGAAAAAAAAAAAAAAAGAAGAAGAAGAAGCC…
                AAGAAGAAGAAGAAG
  (A)15 ✓   (AAG)5 ✓   →  (A)15{-2}(AAG)5

      Classify

      p2   (CA)7                    # each SSR on its own
p2   (TG)7                    # 5 bp later: not merged
c*   (A)13{-1}(AG)8           # sharing 1 base
i2   (AG)7t(AG)4    purity 0.957 # substitution
i3   (CTT)6c(TCT)5   purity 0.971 # deletion, phase shift

      Install

      Install the command-line tool

      $ cargo install --git https://github.com/LaBiOmicS/nextSSR nextssr


$ nextssr misa genome.fa misa.ini


$ nextssr run genome.fa.gz -o results/genome --imperfect --primers -t 8


$ nextssr run genome.fa --primers --num-pairs 3 --epcr
$ nextssr epcr -p genome.fa.primers.tsv other_genome.fa.gz -o transfer
